🐙 GitHub storage — fully automatic, charts included (recommended)
How to set it up — 5 minutes, once
  1. Open github.com/new → name it scalein-data → choose Private → tick Add a README file → Create repository.
  2. Open github.com/settings/personal-access-tokens/new → name: ScaleIn → expiration: 1 year (the maximum) → Repository access: Only select repositories → pick scalein-data → Repository permissions → Contents: Read and write → Generate token → copy it (starts with github_pat_).
  3. Paste the repo name and the token below, then press Test connection. After that sync runs by itself — nothing to press. Do the same paste on each device.
The token is stored only in this browser and only works on that one repo. It expires within a year; when it does you'll see a clear message — just make a new one.
